PROJECT 01 • REAL-TIME AI VOICE ENGINE Doulingo_speak

Multi-Model Architecture & low-latency Pipeline

A real-time conversational speaking platform for interactive English learning that eliminates the 3–5 second audio turnaround bottleneck using parallel dual-model workers and sub-150ms pre-buffered audio fillers.

PYTHON FASTAPI WEBSOCKET ELEVENLABS ASYNCIO
142MS TIME-TO-FIRST-AUDIO PARALLEL DUAL-MODEL CEFR GRAMMAR WORKER

Production Bottlenecks

  • 3–5s Turnaround Latency: Standard REST audio endpoints created awkward silences that destroyed user conversational flow.
  • Repetitive Dialogue: Unconstrained LLMs drifted from structured curriculum lesson goals.

Technical Decisions ("Under the Hood")

  • Sub-200ms Latency Masking: Pre-buffered instant audio fillers ("Hmm...", "Let me see...") play in 142ms while LLM chunks generate.
  • ElevenLabs WebSocket Turbo Stream: Direct chunk streaming over WebSocket (`/stream-input`) replacing blocking REST calls.

PROJECT 02 • MULTIMODAL VISION AI & RULE ENGINE Furniture_Soft

Vision AI Interior Quotation & Automated Bill-of-Quantities (BoQ) System

An automated spatial recognition engine transforming 3D perspective renders into strictly typed BoQ estimates for wood manufacturing workshops with 100% exact pricing math.

PYTHON GEMINI-VISION PYDANTIC POSTGRES-JSONB NEXTJS
45-MIN ➔ 30-SEC BOQ CREATION 100% MATH ACCURACY (PYDANTIC GUARD) ASYNC 202 JOB QUEUE

Production Bottlenecks

  • 45-Min Manual Quoting: Workshop owners lost nearly an hour manually typing dimensions into Excel per prospect.
  • LLM Math Hallucinations: Pure vision LLMs hallucinate math calculations and invent invalid JSON schema keys.

Technical Decisions ("Under the Hood")

  • Pydantic Schema Guard (`extra='forbid'`): Guarantees zero extra fields or corrupted data types in LLM output.
  • Python Rule Engine + PostgreSQL JSONB: LLM detects items only; Python engine computes 100% exact pricing based on workshop tariffs.

PROJECT 03 • DECOUPLED AGENTIC AI & MICROSERVICES WMS_Root

Decoupled Warehouse Orchestration & Agentic AI Platform

A high-performance warehouse ecosystem combining gRPC microservices, ACID transaction isolation, LangGraph stateful reasoning agents, and 19 Model Context Protocol (MCP) tools.

PYTHON LANGGRAPH MCP-SDK GRPC REDIS-STREAMS CHROMADB
3 SUBMODULE DECOUPLED ARCH 19 MCP OPERATIONAL TOOLS 20MS REDIS MICRO-BATCHING

Production Bottlenecks

  • High-Concurrency Stock Races: Multi-warehouse allocation risks inventory overselling under high traffic spikes.
  • Unsafe Autonomous AI Actions: Direct LLM execution risks data corruption without strict MCP tool boundaries.

Technical Decisions ("Under the Hood")

  • 3 Decoupled Submodules: `WMS_Core` (FastAPI + gRPC + PostgreSQL), `WMS_AI_Services` (LangGraph + RAG), and `WMS_MCP_Server` (19 Tools).
  • ACID & Distributed Locks: Row-level PostgreSQL locks combined with Redis `SET NX EX` + Lua scripts for zero race conditions.

✦ ENGINEERING PHILOSOPHY

How I Build Production AI Systems

Core engineering principles to ensure AI applications survive real-world scale and production traffic.

👈 Vuốt ngang để xem 3 nguyên tắc 👉
⚙️

1. Deterministic Over Magic

Never trust unvalidated raw LLM text strings. Every payload must pass strict schema validation, type checks, and bounded ranges before touching production databases or clients.

⏱️

2. Perceived Latency is UX

When model generation takes time, intelligent audio buffering, streaming tokens, pre-buffered audio fillers, and optimistic UI updates make applications feel instant.

🔄

3. Graceful Fallbacks by Design

AI APIs fail, timeout, or hit rate limits. Robust systems require automated retries, exponential backoffs, circuit breakers, and fail-safe text degradation.
