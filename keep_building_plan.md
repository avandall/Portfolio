## 🔁 1. The 30-Minute Case Study Framework (3-Beat Shape)

Whenever a new project, feature, or production milestone ships, follow this standardized 3-Beat template to document and publish it within **30 minutes** without touching complex CSS or restructuring the layout.

```
                   THE 30-MINUTE CASE STUDY ENGINE
┌─────────────────────────────────────────────────────────────────────────────┐
│ BEAT 1: THE BOTTLENECK (The Engineering Problem)                            │
│ • State the concrete bottleneck (e.g. Latency, Hallucination, Race condition)│
│ • Quantify the baseline friction (e.g. 5,000ms delay, 18% error rate)       │
├─────────────────────────────────────────────────────────────────────────────┤
│ BEAT 2: THE TECHNICAL DECISION (What I Did)                                 │
│ • 2-3 architectural decisions (e.g. Dual-model async, Redis micro-batching) │
│ • 1 Real Proof Capture (DevTools trace, Pydantic schema, Terminal log)     │
├─────────────────────────────────────────────────────────────────────────────┤
│ BEAT 3: THE MEASURABLE OUTCOME (What Came of It)                            │
│ • 3 Metric Badges (e.g. TTFA < 200ms, 100% Schema Guard, 0% Data Loss)      │
│ • Core engineering takeaway or trade-off acknowledged                        │
└─────────────────────────────────────────────────────────────────────────────┘
```

### ⚡ Step-by-Step 30-Minute Execution Workflow:
1. **Minute 0–10 (Capture Evidence):** Take 1–2 raw screenshots from DevTools Network tab, terminal logs, or system architecture diagram. Save to `assets/captures/projX_capture.png`.
2. **Minute 10–20 (Draft Content):** Fill the 3-Beat markdown structure with clear metrics and code references.
3. **Minute 20–25 (HTML Insertion):** Copy a template `<article class="case-study-card">` in `index.html` and paste the new text and image links.
4. **Minute 25–30 (Git Deploy):** `git add . && git commit -m "feat(portfolio): add case study X" && git push origin main`. The live portfolio updates automatically via GitHub Pages / Netlify!
